## How an agent should consume this repo

1. Read **`SOUL.md`** first — it installs the personality, decision laws and quality bar.
2. Read **`AGENTS.md`** — the operating contract (how to think, price, ship).
3. Load only the skill modules needed for the task from `skills/*/SKILL.md`.
4. Consult **`PRICING.md`** before quoting any work, and **`PROJECTS.md`** to trace every skill back to its source project.

For Claude Code / Claude skills: clone this repo and reference `SOUL.md` in your instructions.
For any other agent: paste `SOUL.md` as system context, then load modules on demand.
